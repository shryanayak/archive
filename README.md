This is a themed web app to track all your borrowed and returned books with animated library date stamps.
This includes support to search your reads across Google Books & OpenLibrary/Goodreads repositories. 
You can even manually add your record in case the search comes back blank.
The update includes date-stamped checkout & return record animations, as well as a feature to add custom book notes/reviews.
The data is stored automatically to your browser's local storage.
